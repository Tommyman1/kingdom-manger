# Kingdom Manager v3.1.9 — Container Profile Navigation

- Adds a visible **🛡 Profile** button to every container row.
- Clicking the container name opens the same Security Profile.
- Keeps the entire row clickable for profile access.
- Disables **Start** while a container is already running.
- Preserves Restart, Stop, Trivy, Update, and policy controls.
- Adds responsive action wrapping so controls stay visually attached to each container.
- No database migration or backend security-engine changes.
